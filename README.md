# Fake News Analyser

This project focuses on detecting fake news using machine learning and natural language processing techniques.

The project includes text preprocessing, data analysis, model training and evaluation. A news sample can be provided to the application for classification.

## Project Overview

The main objective of the project is to classify news content as real or fake based on patterns learned from the training data.

The project covers:

1. Data preprocessing
2. Text cleaning
3. Exploratory data analysis
4. Feature extraction
5. Model training
6. Model evaluation
7. Fake news prediction

## Dataset

The dataset used for the analysis is processed and prepared before being used for model training.

The preprocessing stage includes cleaning the text and converting the news content into features that can be used by the machine learning model.

## Natural Language Processing

The project uses NLP techniques to process news articles before classification.

The main stages include:

* Text cleaning
* Removal of unnecessary content
* Feature extraction
* Text classification

The complete analysis and implementation can be found in:

```text
fake_news_analysis.ipynb
```

## Fake News Detector

The `fake-news-detector` directory contains the application used for testing the trained model.

A sample news article can be provided as input and processed by the system to generate a classification result.

A sample input is included in:

```text
news sample.txt
```

## Running the Project

Clone the repository:

```bash
git clone https://github.com/Tejeshwar-23/fake_news_analyser.git
cd fake_news_analyser
```

Install the required libraries:

```bash
pip install pandas numpy scikit-learn jupyter
```

Open the analysis notebook:

```bash
jupyter notebook fake_news_analysis.ipynb
```

Run the notebook cells in order to reproduce the analysis and model training.

For the application, refer to the files inside the `fake-news-detector` directory.
